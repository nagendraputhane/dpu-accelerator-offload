DAO Release 25.05.0
===================

About DAO and Guides
--------------------
This release covers important updates to DAO. For further details, please refer to our guides:
- **DAO Overview:** An introduction to what DAO is and how it works.
- **User Guides:** Detailed documentation and whitepapers.

New DAO Features
----------------
This section outlines the enhancements introduced in this release.

### Added Features

- **Packages:**  
  New packages have been integrated into DAO.
  
- **Documentation:**  
  New DOCs and whitepapers are now available.
  
- **Platform Support:**  
  Added support for multiple Ubuntu versions, enhanced compiler support, expanded toolchain availability, and other global enhancements.

### Removed Features

- **Global Removals:**  
  Any features or components that are no longer supported have been removed.
